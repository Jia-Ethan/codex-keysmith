使用方式

01 先看计划PREVIEW

看清将要发生的改变

装之前先给出一份计划，你可以完整看过再决定。

确认前什么都不写入

默认只预览。没有你的确认，Codex 不会被改动。

不满意可以停在这里

这一步可以反复看，不必继续。

02 确认后装上APPLY

把指令交给 Codex

确认之后，才把这一份指令装进本机 Codex。

不改软件本身

Codex 程序保持原样。

不碰账号和密钥

登录信息和密钥都不会被读取。

03 新对话生效LIVE

重新打开，新开一轮

新开一轮 Codex 对话，才会用上这份指令。

随时可以整份撤走

同样先看计划，确认后再恢复。

撤走后回到原来

指令被拿掉，Codex 回到安装前的使用方式。
