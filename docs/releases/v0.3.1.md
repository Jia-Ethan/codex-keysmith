# codex-keysmith v0.3.1

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

新增首批三个场景包：`cyber_keystone`、`aiml_toxigen` 和 `chem_rdkit`，支持 macOS 与 Linux 的场景部署和本地验证。

- 三个场景包均提供任务说明、few-shot 数据、自包含验证脚本，以及正例、负例和篡改 fixtures。
- `chem_rdkit` 只读检查当前 Python 环境中的 `rdkit>=2022.9`，不会安装或修改依赖。
- 修正 validator 退出码：输出无效返回 1，输入缺失、格式错误或 checksum 漂移返回 2。
- 加固依赖探测，避免工作目录或 `PYTHONPATH` 影响结果，并禁止写入 Python 字节码。
- 部署文件发生漂移时，卸载继续 fail closed，并原样保留用户文件与事务证据。
- 既有 `example_fixture`、指令部署命令和 schema v1 语义保持不变，无需迁移。

本次正式 Release 提供单文件 CLI、包含四个场景目录的源码 ZIP、tar.gz 与 `SHA256SUMS`。单文件 CLI 不内嵌场景库，使用场景功能时需从同版本源码归档运行，或显式提供绝对 `--scenario-root`。

本次不含 scenario bundle、hooks、GUI 场景页面、Windows `win32` 场景验证或真实模型跑分。桌面安装包继续使用 `desktop-v0.2.0-beta.6` 预发布版本。
