# codex-keysmith v0.3.3

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

M2 第二阶段：发布可重复的密封场景 bundle `codex-keysmith-scenarios-v0.3.3.bundle`。包内是 `index.json` 与完整 `scenarios/` 库；index 中每个 `source_digest` 使用既有 M1 算法，index 自身不自哈希，外层摘要只出现在 `SHA256SUMS`。

单文件 CLI 不内嵌场景库。离线使用时下载同版本 bundle 或源码目录，并用 `SHA256SUMS` 校验后通过绝对 `--scenario-root` 指向密封 `.bundle`、含 `index.json` 的解包目录，或 `scenarios/`。冻结 sidecar 嵌入同版本 bundle；资源完好且摘要匹配时不必再传 `--scenario-root`，缺失或漂移则明确失败。

三个生产场景仍只声明 `darwin` / `linux`。`example_fixture` 继续承担 Windows 生命周期。本次不含 hooks、GUI 场景页、真实跑分、网络下载或新的 Desktop 安装包。已发布的 `v0.3.2` 及更早 tag / 资产保持不变。
