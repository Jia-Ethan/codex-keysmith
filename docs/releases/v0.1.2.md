# codex-keysmith v0.1.2

## 简体中文

v0.1.2 修复 CCSwitch 等工具修改 `config.toml` 后误报“配置已漂移”的问题。卸载现在只处理 `model_instructions_file`，并保留模型、Provider 等其他设置。兼容 v0.1.0/v0.1.1 的现有部署，无需先卸载。Windows 仍为 beta。

## English

v0.1.2 fixes false config-drift errors after CCSwitch edits `config.toml`. Uninstall now preserves other settings. Existing v0.1.0/v0.1.1 deployments stay compatible. Windows remains beta.
