# codex-keysmith v0.5.1

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

新增 `--preset lean`。如果你在用 gpt-5.6-sol，最近一定遇到过那种"网络安全风险"拦截——8 月底起上游对这条模型线收紧了，v0.5.0 的提示词在这上面会频繁触发。lean 就是为此准备的：把触发拦截的部分全部去掉，实测拦截大幅回落，正常安全工作基本不再被打断。

两点提醒：

- 个别"直接要完整利用代码"的请求仍可能被拦，是上游限制，换个问法（要模板、地址留占位符）就能过。
- 配置里 `model_reasoning_effort` 如果是 `max`，改成 `medium`——`max` 在 sol 上会卡到超时。

现有 preset 没有任何改动，默认行为不变。切换方法：

```bash
python3 codex-instruct-vX.Y.Z.py --codex-dir ~/.codex --preset lean --yes
```

装完开新会话生效。本次不更新桌面版安装包。
