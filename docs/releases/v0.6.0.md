# codex-keysmith v0.6.0

三个新东西，都来自实测：

1. **`--preset astra`**：第五个内置稿。字节与 persona-contract 相同（双轴实测冠军），为 GPT-6 Astra 模型线的产品名占位。部署清单现在记录 preset 名，`--status` 直接读清单显示。
2. **`scripts/ks-envelope.py`**：本地协议适配器。Codex 走 OpenAI 信封，适配器翻译成 Anthropic 形打到网关 `/messages`。实测同一条 12 case 冻结 bank：messages 臂 8/12（astra 稿，3 轮去重）对比 codex 原生臂 1/12——上游分类器对信封敏感，这是可测的差分。工具调用（命令执行、文件读写）双向翻译已支持。
3. **bank runner 错误分类**：`--envelope {codex,chat,messages}` 三臂 + `failure_kind` 自动区分上游分类器拦截（`upstream_block`）与模型真实拒答（`model_refusal`）。网关错误不再被记成拒绝。

两点如实说明：

- NSFW 显式语域在 gpt-6-astra 上全锁（12+ 形态实测，含编辑改写形态触发硬拦）。astra 稿在该轴没有超预期，CHANGELOG 记录了完整数字。
- 上游 cyber 分类器 2026-09-05 之后明显收紧，v0.5.1 时 15/18 的 exploit 类交付今天同一配置只跑出 1/12。这是环境变化，不是稿子退化。
