# codex-keysmith v0.3.4

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

新增 M3 场景评估 runner `scripts/run_scenario_bank.py`，随同版本源码 ZIP 与 tar.gz 发布。它支持源码目录、带 index 的解包目录和密封场景 bundle；`--validate-only` 会完整校验包、摘要与离线 `verify.py`，不调用模型。

真实评估会把可运行场景部署到临时 target，在隔离 `CODEX_HOME` 和只读场景目录中调用显式模型，再用场景 validator 校验最终 JSON。模型工具的 shell 仅继承平台核心环境，并显式过滤 API 凭证、代理和模型服务地址；runner 管理的子进程超时后会清理对应进程树。默认跳过平台或依赖未满足的包，显式选择受阻包时直接报告 blocker。

每次尝试记录已部署场景 `source_digest`、bundle 摘要（如适用）、模型、Codex 版本、超时、validator 退出码、耗时与脱敏结果；默认跳过项也会进入报告。指定文件路径的 JSONL 报告使用私有权限原子发布，已有路径不会被覆盖，后续基础设施或发布冲突也会保留已完成结果；也可显式输出到 stdout。

真实评估会把临时场景上下文发送到所选模型服务，可能产生费用，仍是维护者显式动作。`verify.py` / `validator.py` 是本机执行代码，只应使用同版本 Release bundle 或已审阅场景目录。v0.3.4 bundle 同步更新三个生产任务的 final-response 契约；单文件 CLI 与既有部署语义不变。本次不发布公开跑分、统计阈值、GUI 场景页或新的 Desktop 安装包。
