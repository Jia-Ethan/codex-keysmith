# codex-keysmith v0.3.5

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

新增源码 GUI 场景库页：可以查看场景包与 blocker，选择显式目标目录后预览部署、查看状态、按 `deployment_id` 卸载并恢复中断事务。预览会绑定规范化目标与场景/部署身份，切换选择或收到过期异步响应时不会误用旧结果；写操作无论成功、失败或超时都会保留诊断并刷新目标状态。

M3 场景 runner 现在会对 `OPENAI_BASE_URL` 执行 fail-closed 校验，只接受安全的绝对 HTTP(S) 根路径，拒绝 userinfo、query、fragment、反斜杠及非法 host/port，并规范化 scheme、IDNA/大小写 host、IPv4/IPv6 和末尾斜杠。兼容 endpoint 会作为隔离 custom provider 注入，不会在 `--ignore-user-config` 下回落到默认 OpenAI 地址；报告和错误会脱敏凭证及原始/规范化 endpoint。

本次不发布新的 DMG 或 NSIS。公开 Desktop 安装包仍为 `desktop-v0.2.0-beta.6` unsigned Beta，不包含该场景页；`v0.3.4` tag 与既有资产保持不变。
