# codex-keysmith v0.3.0

<!-- WINDOWS_FRESH_DEPLOYMENT_POLICY: EXPLICIT_BETA -->

新增 target-local 场景部署：场景状态与事务证据只保存在显式目标目录中，并通过 `deployment_id` 精确查看、卸载和恢复。

- 支持场景列表、预览部署、状态检查、精确卸载和中断恢复。
- 增加多 target 重复部署、漂移、异常节点、路径重绑和并发冲突保护。
- 内置无依赖示例场景与跨平台 `verify.py`，便于本地验证完整流程。
- 既有指令层 `.codex-keysmith-manifest.json` schema v1 与命令语义保持不变，无需迁移。

本次正式 Release 提供单文件 CLI、源码 ZIP、tar.gz 与 `SHA256SUMS`；桌面安装包继续使用 `desktop-v0.2.0-beta.6` 预发布版本。
