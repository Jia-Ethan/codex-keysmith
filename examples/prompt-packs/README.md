# Prompt pack examples

These Markdown files are optional examples for `codex-keysmith install --pack ...`.
They are not a policy engine and do not guarantee that a model will change behavior.
`codex-keysmith` remains an instruction-file installer for Codex CLI configuration.

Available examples:

- `ctf-security-research.md` — authorized CTF / security research workflow framing.
- `general-research.md` — source-backed general research workflow framing.
- `coding-strict-engineering-agent.md` — stricter repository engineering workflow framing.

Use your own Markdown file with `--file` when you need a real project-specific instruction set.
